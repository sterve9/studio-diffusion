# Ressources externes — zone de gel

Ce dossier stocke des ressources rencontrées **pendant** le déroulé de la
méthode, avant l'étape qui donne le droit de s'en servir.

## Pourquoi un gel

Une ressource trouvée à l'étape 1 qui propose une solution technique
contamine `02.Probleme_Metier.md` : on ne sait plus si le problème est
formulé à partir des chiffres du projet, ou à partir du sommaire de la
ressource. La méthode interdit de choisir la solution avant d'avoir écrit
le besoin.

Rien n'est jeté. Tout est daté, classé, et porte **l'étape à partir de
laquelle on a le droit de l'ouvrir**.

## Règle

1. Toute ressource entre ici avec sa date de capture et son contenu intégral.
2. Elle porte une **étape de déblocage**. Avant cette étape, on ne la lit pas
   pour décider — seulement pour vérifier qu'elle est bien rangée.
3. Une ressource ne peut jamais faire réécrire une étape déjà écrite.
   Le besoin est daté ; il est antérieur.
